## Re-evaluation protocol (identical to training)

* File list: `data/xBD/{train,tier3}/images`, sorted, filter
  `*_pre_disaster.png` — exactly as `train_segformer_loc.py`.
* Split: `train_test_split(np.arange(9168), test_size=0.1,
  random_state=3, shuffle=True)` — **no new random split**. Verified:
  9168 total / 917 val, matching the original training log.
* Loading: full-resolution 1024×1024, no augmentation,
  `preprocess_inputs()`, binarization `mask > 127` — same as training
  `ValData`.
* Decision threshold: sigmoid output > 0.5 — same as training `validate()`.
* Model: `GFformer_one`, `state_dict` loaded strictly, `eval()` mode.

Run: `/usr/local/miniconda3/envs/gft/bin/python eval_stage1.py`
